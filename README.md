# Personal CV & Portfolio

A responsive personal CV website for an aspiring web developer. The page includes a profile, career objective, basic information, education, technical and professional skills, projects, academic experience, achievements, and social links.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## Personalize before publishing

This workspace starts with sample copy and placeholder details. Update `index.html` with your real name and title, introduction and objective, location and email, education, achievements, project descriptions and repository links, and your personal GitHub, LinkedIn, and other social URLs. Replace the portrait image URL with your own professional photo. Remove any education or project entries that do not apply. Do not publish confidential personal information.

## Run locally

Open `index.html` in a browser, or run a static server from this directory, for example:

```sh
npx serve .
```

## Deploy to Vercel

Import this repository into Vercel and deploy it as a static site. No build command is needed; use `.` as the output directory. Add the final public URL here after deployment.
